## 怎么测

**主路径（手工强制唤醒，推荐）：**

```bash
uv run harness schedule apply pi-test --pack pi-demo
uv run harness schedule tick pi-test --rule research-tick
```

`--rule` 会忽略 `enabled: false` 与 interval，适合反复干跑。

**真实定时（只测一次 5m）：**

1. `local/timer-smoke.yaml`：`interval: 5m` + `script` 写 marker（避免为测时钟浪费 LLM）
2. crontab 每分钟 `harness schedule tick pi-test`
3. 首 tick 立即 FIRED；约 5 分钟后再 FIRED 一次即够
4. 将 `timer-smoke` 设 `enabled: false` 并 `reload`；日常仍用 `--rule research-tick`

生产研究规则 `research-tick` 默认 disabled @ 4h，需要时再 local shadow 打开。
