# 研究工作区

这里放**具体项目**。公司研究和行业研究平铺在同一层，不要再按市场/年份拆目录。

共用结论、关注名单、跨项目教训在 `../memory/`，不要复制到每个项目里。

## 怎么开新项目

1. 建目录：`公司-<简称或代码>` 或 `行业-<名称>`
2. 从 `_模板/公司.md` 或 `_模板/行业.md` 拷内容到该目录的 `基本面.md` / `消息面.md`
3. 写一份短 `README.md`（一句话 + 当前判断）
4. 在 `索引.md` 加一行

## 每个项目建议有

| 文件 | 内容 |
|------|------|
| `README.md` | 一句话、当前判断（观望/值得跟/避开）、下次复查条件 |
| `基本面.md` | 生意、质量、成长、估值粗框、风险、我可能错在哪 |
| `消息面.md` | 近期新闻与讨论，每条带来源和日期 |
| `来源.md` | 用过的链接、公告、研报 |

## 命名例子

- `公司-贵州茅台` 或 `公司-600519`
- `公司-宁德时代`
- `行业-白酒`
- `行业-新能源车`
